# Deploy Hotel Jatashankar

This folder uses `https://jatashankarhotel.com` as the canonical website address.

1. Copy these files into the Git repository that Vercel deploys, then commit and push them to `main`.
2. In Vercel, add `jatashankarhotel.com` and `www.jatashankarhotel.com` under **Project Settings > Domains**. Choose one production domain and redirect the other one to it.
3. Point the DNS records shown by Vercel to the project. If the former domain is still live, set a permanent (301) redirect to `https://jatashankarhotel.com`.
4. In Google Search Console, verify `https://jatashankarhotel.com` and submit `https://jatashankarhotel.com/sitemap.xml`.
5. Update the Google Business Profile website field to `https://jatashankarhotel.com` and keep the address, telephone number and opening hours identical to the website.

Do not publish the site until the Vercel domain and DNS configuration are active; otherwise the canonical URLs will not resolve.
